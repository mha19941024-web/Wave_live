# Wave Live

نسخة Android منظمة وجاهزة للبناء التجريبي.

Build command:
gradle :app:assembleDebug

Firebase project: wave-live-b285f

ضع google-services.json داخل app/ إذا أردت تفعيل Google Services plugin في خطوة لاحقة.

ملاحظة: واجهة البث والهدايا موجودة كبنية أولية؛ تشغيل فيديو Live فعلي، العملات، المدفوعات، والموديريشن يحتاج ربط خدمات الإنتاج وواجهات الـBackend.
